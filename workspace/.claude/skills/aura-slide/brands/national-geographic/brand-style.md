# National Geographic — Brand Style

## Visual Theme & Atmosphere
Formal, documentary and iconic: white pages, black type, square corners, big serif headlines, and one unmistakable
device, the thick yellow rectangle that frames the world's best nature photography. Light theme.
**Aura rule: never a dark background in this theme**, even though the magazine often uses black.

## Colors
| Role | Hex | Notes |
|---|---|---|
| Background | `#ffffff` | always light |
| Primary | `#000000` | text and rules |
| Accent (one only) | `#ffcc00` | the yellow border; never used for text (1.5:1 on white) |
| Link | `#0066cc` | on the site only |
| Text Primary | `#000000` | |
| Text Muted | `#333333` | |
| Border | `#ffcc00` | the frame |

**Color scheme:** light
**Accent rule:** yellow appears only as the frame and the small frame mark before the kicker.

## Typography
Site faces: GeoBrand (sans), GeoEdit (editorial), Georgia (serif headings), Open Sans.
Aura blend (SIL OFL):
- **Display:** Source Serif 4, weight 600, optical size 60
- **Text + labels:** Open Sans. Section labels are uppercase, 700, letter-spacing 0.12em.

| Role | Size |
|---|---|
| H1 | 112 px, line-height 1.08, −0.01em |
| Kicker | 28 px, uppercase |
| Body | 36 px |
