# Nothing — Brand Style

## Visual Theme & Atmosphere
Industrial, raw and monochrome: near-black type on a light grey field, square corners, visible grids and
dot-matrix lettering borrowed from LED displays, with a single yellow signal colour. Brutal, high-contrast, technical.
Light theme.

## Colors
| Role | Hex | Notes |
|---|---|---|
| Background | `#f4f4f4` | light grey field; `#ffffff` for panels |
| Primary | `#040404` | near-black: type, rules, dots, secondary buttons |
| Accent (one only) | `#ffc700` | signal yellow: primary button (`#040404` text on it, 13:1), highlights |
| Text Primary | `#040404` | |
| Text Muted | `#868686` | large text only |
| Border | `#040404` | 2–4 px solid rules; `#c9c9c9` for faint grid dots |

**Color scheme:** light
**Accent rule:** yellow is the only colour. Everything else is black, white or grey.

## Typography
Site faces: **NType82** (display), **Ndot** (dot matrix), **Geist / Geist Mono**, **Lettera Mono**.
Aura blend (all SIL OFL):
- **Display:** Geist 900, uppercase, −0.04em
- **Emphasis:** Doto 900 (dot matrix, stands in for Ndot) on a yellow block, one phrase only
- **Body + labels:** Geist Mono 400/500; kicker uppercase in `[ brackets ]`

| Role | Size |
|---|---|
| H1 | 112 px, line-height 1.05 |
| Kicker | 28 px mono |
| Body | 36 px mono |

## Spacing & Shape
- Base grid: 8 px
- Border radius: 0 (buttons 4–8 px on the site)
- Shadows: none
- Framework hint: custom
